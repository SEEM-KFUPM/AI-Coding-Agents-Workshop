# Environment Management

Reproducibility gets easier when the environment is explicit.

## Minimum Rule

Write down the environment in a file before the project becomes complicated.

## Options

- `environment.yml`
- `requirements.txt`
- `pyproject.toml`

## Practical Advice

- Prefer one clear workflow over many competing ones
- Avoid undocumented manual package installs
- Update the environment file when the project changes materially
