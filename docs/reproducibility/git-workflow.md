# Git Workflow

Git is part of the development process, not a final upload step.

## Recommended Pattern

1. Start the repo early
2. Make one small change
3. Commit with a meaningful message
4. Repeat at each milestone

## Good Commit Examples

- `Initialize workshop starter`
- `Add first plotting script`
- `Document assumptions and expected outputs`
- `Add smoke test for data loading`

## Review Habit

Before moving on, inspect:

```bash
git status
git log --oneline --decorate
```
