# Project Structure Guide

Good workshop projects should be understandable at a glance.

## Recommended Shape

```text
README.md
data/
src/
tests/
results/
```

## Principles

- Put reusable code in `src/`, not only in notebooks
- Separate raw inputs from processed outputs
- Keep results reproducible, not mysterious
- Document assumptions close to the work

## A Good Question to Ask

`If I revisit this in three months, will I understand how it works?`
