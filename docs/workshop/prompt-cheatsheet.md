# Prompt Cheat Sheet

## Good Starter Prompts

- `Read this repository and summarize the project structure.`
- `Propose a small implementation plan before changing code.`
- `Implement only the first step and stop after that.`
- `List assumptions and possible failure modes before writing tests.`
- `Review this code for bugs and reproducibility risks.`

## Useful Prompt Patterns

### For planning

`Turn this task into 4 small milestones with clear outputs.`

### For safer coding

`Change only the files required for this step and explain what you changed.`

### For scientific caution

`List units, assumptions, and validation checks that should be confirmed by a human.`
