# Suggested Session Flow

## Part 1: Framing

- What coding agents are good at
- Where they fail
- Why reproducibility and review still matter

## Part 2: Guided demo project

- Read the demo brief
- Define milestones
- Create or inspect project structure
- Produce a first output

## Part 3: Improve the project

- Refactor
- Add validation
- Improve prompts
- Improve documentation

## Part 4: Git and wrap-up

- Review commit history
- Summarize assumptions
- Identify next steps
