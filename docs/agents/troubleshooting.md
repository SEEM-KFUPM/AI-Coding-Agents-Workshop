# Troubleshooting

## Common Setup Problems

### Git not found

- Reopen the terminal after installing Git
- Check that Git is on the system path

### Python environment confusion

- Confirm which Python interpreter VS Code is using
- Create a fresh environment if the current one is unclear

### Agent access issues

- Confirm sign-in status
- Confirm the workspace is trusted
- Keep a manual fallback task ready if online features are unstable

## Common Workflow Problems

### The agent changes too much at once

Ask for one milestone only.

### The agent invents details

Ask it to cite the file or note the assumption explicitly.

### Results look wrong

Stop and verify data, units, and expected outputs before more refactoring.
