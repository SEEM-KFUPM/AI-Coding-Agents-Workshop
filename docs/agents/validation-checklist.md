# Validation Checklist

Use this list before you trust a result produced with agent assistance.

## Scientific Checks

- Are the inputs what you think they are?
- Are units stated and consistent?
- Does the result look physically plausible?
- Are key assumptions written down?

## Code Checks

- Is the code readable enough for another person to review?
- Are edge cases handled or at least acknowledged?
- Is there a minimal test or smoke check?

## Reproducibility Checks

- Can someone rerun the workflow from the README?
- Are environment requirements stated?
- Are outputs and expected files described clearly?
