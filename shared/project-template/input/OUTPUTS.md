# Outputs

Describe the expected output format and evaluation criteria for the project.

## Required Deliverables

- Primary code, figures, tables, or any other output
- Short project README
- Tests, examples, or other documentation to demonstrate the output and how to use it

## Output Structure

- keep `input/` folder unchanged
- use `src/` folder for code, including a clear entry point script that runs the code, any necessary helper functions or modules, and README with instructions
- add `requirements.txt` with all dependencies
- add `environment.yml` for conda environment setup
- use `output/` folder for the generated outputs, organized in a clear way (e.g. separate folders for figures, tables, etc.)
