# Presentation

The slide deck is written in Markdown using Marp.

## Files

- `slides.md` - canonical slide source
- `assets/` - images and static assets used by the slides

## Suggested Workflow

1. Edit `slides.md`
2. Preview with Marp for VS Code or the Marp CLI
3. Export to PDF or HTML only when needed

## Notes

- Keep the presentation aligned with the public repository paths
- Avoid event-specific dates in the base deck
- Keep screenshots and diagrams in `assets/`
