# AI Coding Agents Workshop

This repository is the public home for the AI Coding Agents Workshop materials: presentation source, participant guides, reproducibility notes, and structured demo briefs.

## What this repository is for

- A reusable, date-agnostic workshop repository
- A clean starting point for participants who want to understand the course structure
- A reference for good project organization, Git usage, and reproducibility habits
- A public specification for the three demo tracks used in the workshop

## What this repository is not

- It is not a solutions repository
- It does not contain full instructor starter implementations
- The `demos/` folders are brief-driven scaffolds and placeholders, not finished projects

## Start Here

1. Read [presentation/README.md](presentation/README.md) if you want the slide deck source.
2. Read [docs/setup/local-setup.md](docs/setup/local-setup.md) to prepare your machine.
3. Read [docs/workshop/agenda.md](docs/workshop/agenda.md) for the workshop flow.
4. Pick a demo brief in `demos/`.

## Repository Map

- `presentation/` - Marp slides and slide assets
- `docs/setup/` - setup instructions for local tools
- `docs/workshop/` - participant-facing workshop aids
- `docs/reproducibility/` - cross-cutting project and Git guidance
- `shared/demo-spec-template/` - reusable templates for future demo briefs
- `demos/` - the three demo specifications and placeholders

## Demo Tracks

### `demos/01-legacy-figure-reproduction`

Guided exercise focused on reproducing a figure from an older scientific paper.

### `demos/02-paper-results-reproduction`

Research-style exercise focused on reproducing a key result from a published geoscience paper.

### `demos/03-geoscience-webapp`

Application-building exercise focused on a geoscience data-processing or ML workflow with a Gradio interface.

## Expected Participant Outcomes

- Understand how to structure a small research coding project
- Use Git from the beginning instead of treating it as an afterthought
- Work with coding agents critically rather than passively
- Leave with a clearer roadmap for building a reproducible project
