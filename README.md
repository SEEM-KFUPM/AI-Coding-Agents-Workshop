# AI Coding Agents Workshop

This repository is the public home for the AI Coding Agents Workshop materials: presentation source, participant guides, reproducibility notes, demo projects slides and exercises.

## Start Here

1. Read [presentation/README.md](presentation/README.md) if you want the slide deck source.
2. Read [docs/setup/local-setup.md](docs/setup/local-setup.md) to prepare your machine.
3. Read [docs/agents/prompt-cheatsheet.md](docs/agents/prompt-cheatsheet.md) for agent prompt templates and patterns to keep in mind during the demos and exercises.
4. Check demo projects in `demos/`.
5. Try exercises in `exercises/` when you're ready to practice.

## Repository Map

- `presentation/` - Marp slides and slide assets
- `docs/setup/` - setup instructions for local tools
- `docs/agents/` - participant-facing agents guidance and prompt templates
- `docs/reproducibility/` - cross-cutting project and Git guidance
- `template/` - reusable template for projects
- `demos/` - slides for demo projects
- `exercises/` - participant exercises with input and output specifications

## Expected Participant Outcomes

- Understand how to structure a small research coding project
- Use Git from the beginning instead of treating it as an afterthought
- Work with coding agents critically rather than passively
- Leave with a clearer roadmap for building a reproducible project

## Nice to Have

- A small research idea you may want to map into this structure later
