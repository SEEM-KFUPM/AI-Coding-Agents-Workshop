# Contributing

This repository is meant to stay clean, public, and reusable across workshop editions.

## Contribution Rules

- Keep public materials date-agnostic unless a specific event branch needs dated content.
- Do not add instructor solutions or private datasets.
- Prefer short, readable Markdown over dense notes.
- Keep demo folders as specifications and placeholders, not full implementations.
- When changing demo scope, update the demo brief, expected outputs, and milestones together.

## Pull Request Checklist

- The change improves the workshop materials or repository structure
- Public files do not reveal private or licensed material
- Links and paths in Markdown still work
- Demo names and numbering remain consistent

## Style

- Use plain English
- Keep headings short
- Prefer checklists and short sections over long prose walls
