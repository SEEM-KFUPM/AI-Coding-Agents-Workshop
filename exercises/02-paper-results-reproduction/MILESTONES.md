# Milestones

1. Select the paper and define the smallest meaningful target
2. Identify inputs and expected outputs
3. Reproduce the first result
4. Record discrepancies and refine the workflow
5. Summarize what matched and what did not

## Suggested Git Checkpoints

- `Define paper reproduction scope`
- `Add first reproducible result`
- `Document discrepancies and assumptions`
- `Finalize reproducible workflow`
